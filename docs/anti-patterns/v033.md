# FanUI Responsive Anti-patterns

## Shrunk Desktop Evidence

A desktop product UI is reduced until text and controls are unreadable.

**Fix:** crop, stack, simplify chrome, or replace the evidence composition.

## Hidden Without Replacement

Sidebar, Inspector, TOC, or project navigation disappears at a breakpoint with no replacement access path.

**Fix:** drawer, sheet, compact selector, mobile nav row, or sequential section.

## Cramped Split

A desktop split composition remains side-by-side on a narrow viewport, producing narrow text columns and tall word-by-word headings.

**Fix:** stack and deliberately reorder.

## Desktop Toolbar Wrap

Toolbar items wrap unpredictably into two or three lines and obscure current context.

**Fix:** prioritize current context + primary action, collapse secondary tools, or use scroll/menu.

## Runtime Takeover

A console/runtime pane consumes most of the mobile page simply because the desktop pane was stacked vertically.

**Fix:** cap height, internal scroll, collapse, or use a dedicated view.

## Whole-page Horizontal Scroll

The browser page itself scrolls horizontally because a table, graph, or screenshot retained desktop width.

**Fix:** local scroll for tables/tabs; transform graphs/evidence.

## Tiny Touch UI

Desktop 28–34px controls are reused as primary mobile touch targets.

**Fix:** 40–44px touch targets while keeping glyphs visually compact.

## Mobile Empty Canvas

Desktop workspace/evidence geometry survives after side panes disappear, leaving a large unused field beside a tiny active region.

**Fix:** recompute the remaining canvas and let the active task own the width.
